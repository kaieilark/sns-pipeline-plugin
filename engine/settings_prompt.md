# 統括設定 指示書（settings step・エージェント共通）

このパイプラインの設定を、メニュー形式で変更する入口。ランタイムは `SNS_PIPELINE_HOME`
（未設定なら `~/.sns-pipeline`）配下（以降 `$HOME_DIR`）。

## 手順

1. `$HOME_DIR/config.json` があるか確認する。**無ければ未セットアップ**なので、
   「まず初期セットアップ（`sns-setup` / Codexなら setup プロンプト）を実行しますか？」と促し、了承なら setup へ。
2. config があれば、現在の状態を1行で要約する（テーマ数・各テーマの NAME と ENABLED、バックボーン/画像テイストの設定有無）。
3. **次の選択肢を明示して、ユーザーに何をするか選んでもらう**（番号で答えてもらう。対話UIが使える環境なら選択肢提示でもよい）:

```
このパイプラインの設定で、何をしますか？

1. テーマを追加する            … 新しい投稿系統を作る（投稿管理テーブルも自動作成）
2. テーマを一覧・編集する        … 読者/ゴール/誘導先URL/チャットID/表示名 の変更、停止・再開
3. バックボーン（背景・思想）を修正する … HPのURL / 直接入力 / 資料ファイル から作り直す（テーマ指定）
4. 画像テイストを変更する        … Instagram URL / 画像添付 / 説明文 から設定（テーマ指定）
5. ロゴを設定・変更する          … 画像に必ず入れるロゴ画像を登録（テーマ指定）
6. 誘導先(CTA)・読者・ゴールを変える … テーマの狙いを調整
7. テーブル構成を確認・再作成する    … 参考元/投稿管理テーブルの状態確認、不足の作成
8. 現在の設定を一覧表示する        … config の全体像を読みやすく表示
9. 拡張機能（Lark クイック送信）の導入手順を見る
```

4. 選ばれた項目に応じて処理する:
   - 1 / 2 / 3 / 4 / 5 / 6 → **テーマ管理指示書 `theme_prompt.md`** の対応セクション（B / A・E / C / D / D+config.LOGO_FILE / E）を実行する。
   - 7 → **セットアップ指示書 `setup_prompt.md`** のテーブル確認・作成セクションを実行する（既存は壊さない）。
   - 8 → config を整形して表示（`PROFILE` 等の秘匿性の低い項目のみ。WEBHOOK_URL はマスクして表示）。
   - 9 → `setup_prompt.md` の拡張機能セクションを案内する。
5. 変更後は「何を変えたか」「次回ランから反映される」ことを短く報告し、続けて別の設定をするか尋ねる。

## 注意
- 秘匿情報（BASE_TOKEN・WEBHOOK_URL・APP_SECRET 等）は画面表示時にマスクする。ログに平文で残さない。
- 変更は config と `$HOME_DIR/themes/<key>/` 配下のファイルに対してのみ行う。既存レコード・テーブルは壊さない。
- 迷う設定値は安全側の既定を置き、「後からいつでも変更できる」ことを必ず伝える。
