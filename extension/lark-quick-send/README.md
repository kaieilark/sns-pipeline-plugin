# Lark クイック送信

ブラウザで選択したテキストやリンクURLを、右クリックメニューから直接Larkの指定チャットへ送信できるChrome拡張機能です。コピー＆ペーストの手間なく、気になった情報をそのままLarkチャットに転送できます。

## Chromeへの読み込み手順

1. Chromeで `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をONにする
3. 「パッケージ化されていない拡張機能を読み込む」をクリックし、このフォルダ（`lark-quick-send`）を選択する

## 初回設定手順

1. 拡張機能アイコンをクリックして設定画面を開く
2. 「Lark Webhook URL」欄に、送信先チャットのWebhook URLを入力する
3. 「保存」ボタンをクリックして保存する
4. 「テスト送信」ボタンをクリックし、対象のLarkチャットにテストメッセージが届くことを確認する

## 使い方

- **テキストを選択して右クリック** → メニューの「Larkチャットへ送信」をクリックすると、選択したテキストがLarkチャットに送信されます。選択テキスト内にURLが含まれる場合は、そのURLのみが送信されます。
- **リンクを右クリック** → メニューの「Larkチャットへ送信」をクリックすると、リンク先のURLがそのままLarkチャットに送信されます。

送信結果（成功・失敗）はブラウザの通知で表示されます。

## Lark側の前提

送信先のLarkチャットに、あらかじめ「カスタムボット」を追加しておく必要があります。カスタムボット追加時に発行されるWebhook URLを、本拡張機能の設定画面に登録してください。
