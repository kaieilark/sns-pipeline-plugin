# Lark クイック送信

ブラウザで選択したテキストやリンクURLを、右クリックメニューから直接Larkのチャットへ送信できるChrome拡張機能です。送信先チャットを複数登録しておき、送るときに選べます。

## Chromeへの読み込み手順

1. Chromeで `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をONにする
3. 「パッケージ化されていない拡張機能を読み込む」をクリックし、このフォルダ（`lark-quick-send`）を選択する

## 初回設定手順

1. 拡張機能アイコンをクリックして設定画面を開く
2. 「チャット名」に、右クリックメニューへ表示したい名前を入力する（例: SNS素材収集）
3. 「Webhook URL」に、送信先チャットのWebhook URLを入力する
4. 「この送信先を追加」をクリックする
5. 追加された送信先の「テスト送信」をクリックし、対象のLarkチャットにテストメッセージが届くことを確認する

送信先は必要なだけ追加できます。登録後にチャット名やURLを変えたいときは「編集」、不要になった送信先は「削除」から取り除けます。

## 使い方

右クリックメニューには「Larkチャットへ送信」と、その下に「このページをチャットに送信する」の2項目が並びます。

**送信先が1件のとき** — それぞれの項目をクリックすると、その送信先へ直接送られます。

**送信先が複数のとき** — 各項目にカーソルを合わせると、右側に登録済みチャットの一覧が開きます。送りたいチャット名をクリックしてください（「Larkチャットへ送信」「このページをチャットに送信する」それぞれで送信先を選べます）。

送る内容は次のとおりです。

- **リンク（ボタン風のリンク・テキストリンクを問わず）の上で右クリック** → 途中の文字列を選択していても、常にリンク先のURLが送信されます。
- **画像の上で右クリック** → その画像のURLが送信されます。
- **テキストを選択して右クリック**（リンク・画像でない場所） → 選択したテキストがそのまま送信されます。文中にURLが含まれていても、選択した範囲すべてが送られます。
- **何も選択せず、リンクでも画像でもない場所を右クリック** → 「このページをチャットに送信する」から、開いているページのURLが送信されます。

送信結果（成功・失敗）は、どのチャットへ送ったかとあわせてブラウザの通知で表示されます。

## Lark側の前提

送信先のLarkチャットに、あらかじめ「カスタムボット」を追加しておく必要があります。カスタムボット追加時に発行されるWebhook URLを、本拡張機能の設定画面に登録してください。

## 更新履歴

### v1.4.0
- **「このページをチャットに送信する」を新設**。「Larkチャットへ送信」の直下に表示され、何も選択せず・リンクでも画像でもない場所を右クリックしたときに、開いているページのURLを送信できる。送信先が複数のときはこちらもサブメニューで選べる。
- **画像を右クリックしたときにその画像のURLを送信できるようにした**（従来は選択・リンクのみ対応）。
- **リンクの上での右クリックを最優先にした**。以前は「文字列を選択していればそれを優先」していたため、リンク上で一部の文字列を選んだ状態だとリンクではなく選択テキストが送られていた。ボタン風のリンク・テキストリンクを問わず、リンクの上で右クリックした場合は選択の有無に関わらず常にリンク先URLを送るよう変更した。

### v1.3.0
- **右クリックメニューから送信できない不具合を修正**。v1.1.0でバックグラウンド処理を
  ESモジュール（`"type": "module"`）にしたことが原因。モジュール型のservice workerは
  休止状態からイベントで起こされる際、モジュール解決が非同期で走る分だけ
  イベント購読の登録が遅れ、右クリックを取りこぼすことがある。
  v1.0.0と同じ通常スクリプト構成（`importScripts` による同期読み込み）へ戻した。
  設定画面から送信できても右クリックからは送信できない、という症状はこれによる。

### v1.2.1
- **複数登録してもサブメニューが出ず、単独項目のままになる不具合を修正**。
  メニュー再構築が同時に複数走ると互いの結果を打ち消すことがあったため、
  必ず1件ずつ順番に処理するようにした（メニュー作成の失敗も検知できるようにした）。
- **テスト送信を押しても無反応に見える問題を修正**。Chromeのポップアップは高さ600pxで
  打ち切られるため、送信先が2件以上になると画面末尾の結果表示が画面外に出ていた。
  結果表示を画面下端に固定し、送信中はボタンが押せないことも見た目で分かるようにした。

### v1.2.0
- 登録済みの送信先を「編集」できるようにした（チャット名・Webhook URLをその場で修正）
- **選択したテキストが送信されない不具合を修正**。従来は「選択テキストにURLが含まれていればURLだけを抽出」していたため、
  本文中にURLを含む文章を選ぶと本文が失われ、リンク上で文字列を選んだ場合も選択が無視されていた。
  選択があるときは選択内容をそのまま送るよう改めた。

### v1.1.0
- 送信先チャットを複数登録できるようにした（設定画面から追加・テスト送信・削除）
- 送信先ごとに「チャット名」を設定し、右クリックメニューのサブメニューから選んで送信できるようにした
- 設定画面をカード形式の一覧へ刷新（ライト／ダークモード対応）
- v1.0.0 で登録済みのWebhook URLは、初回起動時に「送信先1」として自動的に引き継がれる

### v1.0.0
- 選択テキスト・リンクURLを、右クリックメニューから単一のLarkチャットへ送信する機能
