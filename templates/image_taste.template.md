# 画像テイスト定義 — テーマ: __THEME_NAME__

> このテーマの投稿画像の「見た目の世界観」を決めるファイル。画像生成（Codex等の画像生成モデル）は
> ここを読んでテイストを合わせる。**後からいつでも編集してよい。**
>
> テイストの指定方法は3通り。`MODE` で選ぶ。どれを選んでも、実際のランは下の PALETTE / MOTIFS 等の
> テキストを読んで生成するため、ランがネット接続やブラウザ操作に依存しない（堅牢）。
> `sns-settings`（画像テイストの変更）を使うと、URLや添付画像からこの各項目を自動で埋められる。

```yaml
MODE: description        # instagram_url | image | description のいずれか
REFERENCE:               # MODE=instagram_url ならInstagram等のURL / MODE=image なら image_refs/内の画像パス / description なら空
```

---

## PALETTE（配色）

<主要色・アクセント色をHEXで。例: 背景 #FBFAF7 / 主文字 #061F4B / アクセント #1B61C9 / 罫線 #D8E2EE>

## MOOD（全体の質感・空気感）

<例: 柔らかい水彩、余白広め、彩度低め、落ち着いたビジネス調 など>

## MOTIFS（使うモチーフ）

<例: 窓辺の光、ノートPC、マグカップ、観葉植物。使わないモチーフも書く>

## PEOPLE（人物の可否）

<例: 水彩イラストの人物を入れてよい（写真風は不可）／人物なし など>

## TYPOGRAPHY（文字の扱い）

<例: 見出しは装飾なしのフラットな単色。厚み・影・光沢をつけない>

## LOGO（ロゴ）

<入れる/入れない。入れる場合、config の LOGO_FILE に実ファイルパスを設定し、画像生成モデルに忠実に描かせる。
文字で社名を書いて代用しない。ロゴの色をテーマ配色に合わせて描き替えない>

## FORBID（このテイストで禁止すること）

<例: 濃色の大面積ベタ塗り、金額・数字の強調表示、無機質な質感、装飾絵文字>

## NOTES（自由メモ）

<参考にしたアカウント名や、生成時に気をつけたいことなど>
