# 画像テイスト定義 — テーマ: 会社ブランディング（デモ）

> これは配布物に同梱した**架空のデモ**。セットアップ時は自社の `themes/<キー>/image_taste.md` を作る。

```yaml
MODE: description
REFERENCE:
```

## PALETTE（配色）
背景 #F5F8FC / 主文字 #12233B / アクセント #1B61C9 / サブ #2EC7E6 / 罫線 #D8E2EE

## MOOD（質感・空気感）
清潔なビジネス調。余白広め。彩度は中〜低め。信頼感。

## MOTIFS（モチーフ）
デスク周りの整理された小物、書類の束、シンプルな幾何アイコン。雑然としたモチーフは避ける。

## PEOPLE（人物）
原則なし（人物を入れる場合も主役は情報・アイコン）。

## TYPOGRAPHY（文字）
見出しは装飾なしのフラットな単色。厚み・影・光沢をつけない。

## LOGO（ロゴ）
入れる場合は config の LOGO_FILE に自社ロゴを設定し、画像生成モデルに忠実に描かせる。

## FORBID
装飾絵文字、無機質すぎる質感、根拠のない数値の強調表示。

## NOTES
このデモは description モード。実運用では Instagram URL や添付画像から PALETTE 等を埋めてもよい。
