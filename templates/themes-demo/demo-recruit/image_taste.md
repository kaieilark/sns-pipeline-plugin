# 画像テイスト定義 — テーマ: 採用・募集（デモ）

> これは配布物に同梱した**架空のデモ**。セットアップ時は自社の `themes/<キー>/image_taste.md` を作る。
> 会社ブランディング（デモ）とは**別の世界観**にしてあり、テーマごとにテイストを分ける見本になっている。

```yaml
MODE: description
REFERENCE:
```

## PALETTE（配色）
背景 紙色 #FBFAF7 / 主文字 #12233B / アクセント #E4A94F（ゴールド系）/ サブ #EFD4D3（ローズ）/ 罫線 #E6DDCE

## MOOD（質感・空気感）
柔らかい水彩。余白広め、彩度低め。温かく前向きで静か。在宅の穏やかな空気。

## MOTIFS（モチーフ）
窓辺の光、ノートPC、マグカップ、観葉植物や小枝、ノートとペン。濃色の大面積ベタは避ける。

## PEOPLE（人物）
水彩イラストの人物を入れてよい（写真・写真風は不可）。等身大で穏やかな表情。手元や引きの構図を優先。

## TYPOGRAPHY（文字）
見出しは装飾なしのフラットな単色。厚み・影・光沢をつけない。

## LOGO（ロゴ）
入れる場合は config の LOGO_FILE に自社ロゴを設定し、画像生成モデルに忠実に描かせる。

## FORBID
装飾絵文字、濃色の大面積ベタ塗り、金額・数字の強調表示、無機質な質感。

## NOTES
ブランディング（デモ）が「清潔なビジネス調・ブルー基調」なのに対し、こちらは「水彩・紙色・ゴールド」。
