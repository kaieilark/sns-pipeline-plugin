# sns-theme — テーマ管理

投稿のテーマ（系統）を管理する。素材案テーブルは全テーマ共通の1つ、投稿管理テーブルはテーマごとに分ける。

## 手順
1. `"${CLAUDE_PLUGIN_ROOT}/engine/theme_prompt.md"` を読み、その手順に従う。
2. ランタイムは `SNS_PIPELINE_HOME`（未設定なら `~/.sns-pipeline`）。テンプレートは `"${CLAUDE_PLUGIN_ROOT}/templates/"`。
3. 操作を選ぶ: 一覧（A）/ 追加（B）/ バックボーン設定（C）/ 画像テイスト設定（D）/ 編集・停止・再開（E）。
4. 追加時は、投稿管理テーブル作成 → 素材案テーブルの「テーマ」選択肢追加 → テーマ用フォルダ scaffold → config.THEMES 追記、まで行う。既存テーマ・既存データには触れない。

## 注意
- テーブル・レコードの物理削除はしない。「削除」は `ENABLED:false`（停止）で行う。
- `lark-cli base --help` でテーブル作成・フィールド更新の正確なサブコマンド名を確認してから実行する。
