# sns-settings — 統括設定メニュー

このパイプラインの設定を、メニュー形式で変更する入口。

## 手順
1. `"${CLAUDE_PLUGIN_ROOT}/engine/settings_prompt.md"` を読み、その手順に従う。**専門用語を知らない利用者向けに、選んだ項目を平易な言葉で説明してから作業する**（`engine/setup_prompt.md` §0-1 対話の進め方・用語集に従う）。
2. ランタイム `SNS_PIPELINE_HOME`（未設定なら `~/.sns-pipeline`）の `config.json` を読み、現状を要約する。
3. 次の選択肢を提示し、ユーザーに何をするか選んでもらう（番号で回答可）:
   - テーマを追加する / テーマを一覧・編集する / バックボーン（背景・思想）を修正する / 画像テイストを変更する / ロゴを設定・変更する / 誘導先(CTA)・読者・ゴールを変える / テーブル構成を確認・再作成する / 現在の設定を一覧表示する / 拡張機能の導入手順を見る / バックボーンストック（継続蓄積）を設定・確認する / 画像生成バックエンドを変更する / 素材ライブラリを設定・確認する
4. 選ばれた項目に応じ、`engine/theme_prompt.md`（テーマ操作）または `engine/setup_prompt.md`（テーブル/拡張機能/バックボーンストック/画像生成バックエンド§0-6/素材ライブラリ§3-3）の該当セクションを実行する。
   - **「テーマを追加する」や「バックボーンストックを設定する」で取込元チャットが未確定の場合、必ず `engine/setup_prompt.md` §0-5（チャット作成ガイド）を対話で実行し、得られたCHAT_ID/WEBHOOK_URLをその場でconfig.jsonへ登録する。** 聞きっぱなしにしない。
   - **「画像生成バックエンドを変更する」では、Claude Code自身は画像生成機能を持たないため、必ずユーザーに3択（codex_cli/openai_api/custom_script）を尋ねる。** 黙って既定値にしない。
5. 変更後、「何を変えたか」「次回ランから反映される」を短く報告し、続けて別の設定をするか尋ねる。

## 注意
- 秘匿情報（BASE_TOKEN・WEBHOOK_URL・APP_SECRET 等）は表示時にマスクし、ログに平文で残さない。
- 変更は config と `themes/<key>/` 配下のファイルのみ。既存レコード・テーブルは壊さない。
